# go-transfer-go: что нужно для настоящего запуска

Демо работает целиком в браузере: SMS-код показывается на экране, маршруты, брони и чаты хранятся только на устройстве, ответы водителей в чате смоделированы. Для реального сервиса нужны следующие части.

## 1. Сервер и база данных
- Бэкенд (например, Node.js/NestJS или Python/FastAPI) и база PostgreSQL с расширением PostGIS для гео-поиска.
- Хостинг в ЕС: Hetzner, DigitalOcean, AWS Frankfurt. Для старта хватит одного сервера.

## 2. Вход по телефону
- SMS-провайдер с покрытием по всей Европе: Twilio, Vonage, Infobip. Около 0,05–0,10 € за SMS.
- Дешевле: код через WhatsApp, Viber или Telegram (их многие используют в Молдове и в эмиграции).
- Защита: лимит запросов кода на номер и IP, код живёт 5 минут, 3–5 попыток.

## 3. Карты и геолокация
- В демо карта Европы встроена прямо в приложение (границы стран, города, маршруты дугами).
- Для запуска: бесплатный стек OpenStreetMap + MapLibre или Leaflet, тайлы OpenFreeMap; маршруты и поиск адресов через OpenRouteService или Geoapify (есть бесплатный лимит). Платные альтернативы: Google Maps, Mapbox.
- Нужны: точка на карте с точным адресом, расчёт реального маршрута по дорогам, поиск попутных маршрутов «по пути» (не только старт и финиш), отслеживание машины в реальном времени (WebSocket).

## 4. Чат
- Свой чат через WebSocket (Socket.IO) или готовые сервисы: Stream, Sendbird, Firebase. Push-уведомления: Firebase Cloud Messaging.
- Номер телефона показывать только после брони, чтобы люди не уходили из сервиса.

## 5. Платежи и модель заработка
- Регистрация, поиск, чат и бронь бесплатные. Водитель платит 1 лей за каждое поданное объявление (маршрут). Подписок и комиссий нет.
- Платёжные сервисы для Европы и Молдовы: Stripe (ЕС), MAIB или Paynet (Молдова). Для удержания денег до окончания поездки нужен режим «безопасной сделки» (Stripe Connect).

## 6. Мобильные приложения
- Текущее демо можно сделать PWA (иконка на экране телефона) сразу.
- Для App Store и Google Play: React Native или Flutter. Аккаунт разработчика Apple 99 $/год, Google 25 $ один раз.

## 7. Исполнители и юридическая часть
- Отдельные приложения или режимы для водителей и эвакуаторщиков: верификация паспорта, прав, СТС.
- Договор-оферта и политика конфиденциальности по GDPR (ЕС) и закону Молдовы о персональных данных.
- Посылки и машины через границу: правила о запрещённых вложениях, таможня, страховка груза. Перевозчикам автомобилей нужны лицензия и CMR-накладная.

## Порядок работ
1. Создать репозиторий на GitHub и перенести туда демо.
2. Сделать бэкенд с входом по SMS и базой данных.
3. Подключить карты, затем платежи.
4. Запустить на одном направлении (например, Италия ⇄ Молдова), набрать водителей, затем расширять страны.
