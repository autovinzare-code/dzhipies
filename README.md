# go-transfer-go

Демо-приложение для поездок, посылок и перевозки машин по Европе: вход по номеру телефона, карта маршрутов (OpenStreetMap через MapLibre и OpenFreeMap), маршруты по дорогам и поиск адресов (Geoapify, ключ `GEO_KEY` в app.js; без ключа запасные OSRM и Nominatim), чат с водителем и бронь с сервисным сбором.

Сайт: https://autovinzare-code.github.io/go-transfer-go/ (пока репозиторий не переименован: https://autovinzare-code.github.io/dzhipies/)

Файлы:
- `index.html` — страница и стили. `app.js` — весь код приложения, `pwa.js` — установка на телефон. Код вынесен из страницы, чтобы защита CSP запрещала любые встроенные скрипты.
- `eumap.js` — границы стран (Natural Earth) для запасной карты.
- `euroads.js` — дороги и города Европы (Natural Earth) для запасной карты.
- `config.js` — адрес сервера Supabase. Пустой = демо-режим.
- `supabase/` — база данных (`schema.sql`) и функция входа через Telegram (`functions/tg-login`).
- `НАСТРОЙКА-СЕРВЕРА.md` — как включить сервер и вход через Telegram, по шагам.
- `LAUNCH.md` — что нужно для настоящего запуска.
- `manifest.webmanifest`, `sw.js`, `icons/` — установка на телефон и компьютер без магазинов приложений (PWA) и работа без интернета.

## Установка как приложение (без Play Market и App Store)
Сайт должен открываться по `https://`. Тогда:
- Android и компьютер (Chrome, Edge, Samsung Internet): кнопка «Установить» в шапке приложения или пункт «Установить приложение» в меню браузера.
- iPhone и iPad (Safari): кнопка «Поделиться» → «На экран Домой» → «Добавить». Кнопка в шапке показывает эту подсказку.
- Mac (Safari): меню «Файл» → «Добавить в Dock».

После изменения файлов увеличьте `VERSION` в `sw.js` (v1 → v2), чтобы у пользователей подтянулась новая версия.

Пока `config.js` пустой, данные хранятся только в браузере (демо). С заполненным `config.js` регистрация идёт по коду на почту, а вход по коду, который присылает Telegram-бот, а маршруты, брони, чаты и отзывы хранятся в Supabase (бесплатный тариф).
